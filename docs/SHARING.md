# Sharing

Sharing: portable after fixes - MIT licensed; the author address in the git history is an accepted exposure (docs/AUDIT-ACCEPTED.md)

The tool runs from one HTML file with no dependencies, no accounts and no network except the requests a slide itself causes for a stylesheet, image or font at a web address, which the README discloses. Exports carry neutral names. The MIT license is in LICENSE. The one remaining item before a public release is the commit author address in the history, which the owner decided to keep.
